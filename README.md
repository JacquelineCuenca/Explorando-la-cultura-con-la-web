# Juegos de antes y de ahora

## Descripción del proyecto

Este proyecto busca explorar la evolución de los juegos infantiles a través de las experiencias y opiniones de personas de distintas edades. Mediante entrevistas realizadas en el Mall del Sur, en Guayaquil, se recopila información para comparar los juegos tradicionales con las formas de entretenimiento actuales.

El sitio web permitirá presentar los resultados de esta investigación y mostrar cómo han cambiado las actividades recreativas a través del tiempo.
